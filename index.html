We propose a light regularizer for flow pretraining that widens action spread and smooths the latent space, trading some base performance for strong finetuning.

We want to finetune flow policies without touching the weights.

Problem: both work inefficiently.

Problem 1: Forward flows are highly contractive.

We observe that the forward flow is highly contractive: noises that are far apart in the latent space map to similar actions. This hurts RL exploration, since exploring in noise space can only reach a narrow set of actions.

In the animation, we pick 8 noises that are far apart in the latent space and run the standard flow policy (Vanilla CFM) from each. The 8 resulting actions are nearly identical, and so are the robot's motions.

Problem 2: The reverse process is expansive.

The reverse process inverts the forward flow, so its Jacobian ∂z/∂a is the inverse of ∂a/∂z and its singular values are the reciprocals: every direction the forward flow contracts, the reverse process expands by the same factor. As a result, the latent space intermixes the modes of the action space, which makes learning in the latent space more difficult.

We provide both a visualization of how this appears in the noise and action spaces when learning a noise policy with DSBC, and an explicit measure of the reverse singular values, which shows the high expansion.

Idea: don't let any denoising step contract too much.

LoLip adds one term to the flow-matching loss: for a random unit direction u, it penalizes any denoising step that scales u by less than smin.

Fix 1: LoLip makes the forward flow less contractive.

The same 8 noises, run through the LoLip policy, give 8 clearly different actions and robot motions.

Tradeoff: wider action spread lowers base success; DSBC recovers it.

LoLip keeps each denoising step from contracting, so noises sampled from N(0, I) map to a wider range of actions. The base policy samples its noise from N(0, I) without steering, so some of these actions fall outside the demonstrated motions and more rollouts fail. A noise policy samples only where the demonstrations' noises lie, which removes most of this loss.

LIBERO-90, 20 tasks, base policies trained with the task instruction. Success rate of the base policy alone: Vanilla CFM 86%, LoLip 70%. With a DSBC noise policy trained on the same demonstrations: 89% and 85%.

Shape the noise → action map during pretraining.

PROBLEM
Standard flow policies are highly contractive: moving the noise barely moves the action, which hurts both RL and supervised steering in latent space.
CAUSE
Flow matching fits the action distribution but never shapes the noise → action map.
FIX
LoLip lower-bounds the singular values of each denoising step's Jacobian, which lower-bounds the stretch of the whole flow.
RESULT
A less contractive forward map and more stable inversion give better supervised steering (DSBC) and latent-space RL (DSRL).
